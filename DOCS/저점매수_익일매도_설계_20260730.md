## 4. 고저폭 TOP30 선정 조건 (현행 · `RUN\common_high_range_watchlist_v1.py`)

```python
고저폭(range_pct) = (고가 / 저가 - 1) × 100      # 시가 기준이 아니라 저가 기준
거래대금(value_eok) = value / 100                 # 억원
```

**① 자격일(qualified_day) — 두 조건 동시**
```
전일 고저폭    >= 10.0%   (RANGE_MIN_PCT)
전일 거래대금  >= 100억    (DAILY_VALUE_MIN_EOK)
```

**② 후보 진입**
```
기준일 = 전일 확정 EOD (source_date)
자격일 충족
전일 종가 >= 10,000원   (PRICE_MIN_KRW)   ← 1만원 미만 전부 제외
```

**③ 단계(stage) 분류**

| 단계 | 조건 | 표시 |
|---|---|---|
| 핵심확인대 | streak >= 5 **AND** 5일평균 거래대금 >= 500억 | 👑 crown |
| 확인대 | streak >= 5 | |
| 선발대 | streak 3~4 | |
| 신규대 | 그 외 | |

**④ 정렬 (5단계)**
```
1순위 stage_order (핵심확인대1 → 확인대2 → 선발대3 → 신규대4)
2순위 streak 내림
3순위 avg_5d_range_pct 내림
4순위 min_5d_range_pct 내림      ← 꾸준히 큰 종목 우대
5순위 avg_5d_value_eok 내림
```

**⑤ 상위 30개** (TOP_N = 30)

**산출물**
```
data\common_high_range_top30.json
data\common_high_range_top30.csv    (한글 컬럼)
IPC\micro_watch_high_range.json     {codes[30], crown_codes[], for_date, source_date}
```
- 생성 시각: 08:40 (태스크)
- 2026-07-30 왕관 2종목 = 119850 지엔씨에너지 · 439960 코스모로보틱스
