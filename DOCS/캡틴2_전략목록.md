# 캡틴2 전략 번호표

캡틴2는 **매수 전략만 번호별로 분리**하고, 체결 뒤 상승보유·매도와 주문 안전장치는 공통으로 사용한다.

| 번호 | 전략 ID | 전략 이름 | 매수 상태 | 상승보유·매도 |
|---|---|---|---|---|
| 01 | `C2_01_OPEN_SURGE` | 장초반 급상승 초입 | 월요일 1주 시험 준비 | 캡틴2 공통 엔진 |
| 02 | 예약 | 저점 매수 | 아직 만들지 않음 | 완성 후 공통 엔진 사용 |

## 전략 01 — 장초반 급상승 초입

매수 판정 시간은 KST 09:00 이상 09:20 미만이다.

- 코스닥 보통주, 현재가 10,000원 이상
- 전일 거래대금 후보 또는 장전 갭 후보에 포함. 시가 갭이 3% 이상이면 후보군 밖이어도 감시
- 현재가가 시가보다 높고, 시가 대비 +3%를 이미 넘긴 추격 매수는 금지
- 시가 아래로 내려간 이력이 있는 종목은 전략 02 저점 매수로 넘기고 전략 01에서는 매수 금지
- 실제 매수·매도 방향별 대금이 모두 있어야 함
- 매수대금 비율 70% 이상
- 최근 5초 대금 속도 초당 1,666,667원 이상
- 가격 상승이 3초 이상 지속
- 장 시작 30초 이후에는 5초 속도가 30초 속도의 3배 이상
- 테마 대장은 탈락 조건이 아니라 동시 신호 우선순위 가점

## 월요일 1주 시험 연결

`C2-01 신호 → 기존 주문 안전 경로 → 체결 확인 → 공통 상승보유·매도` 순서다.

- 주문수량: 1주
- C2-01 하루 최대 주문 시도: 1회
- 같은 종목·같은 신호 중복 주문 금지
- 기존 주문 조회, 부분체결, 타임아웃, 재시작 복구 경로 유지
- C2-01 시험 중 기존 EARLY·RAID·PULL·BASE·재가속 신규 실매수는 정지
- 공통매도 계산식은 수정하지 않음. C2-01 공통 프로필의 최종 시간 청산은 15:10
- 매도 신호가 먼저 나오면 15:10까지 기다리지 않고 공통 엔진이 청산 판단

## 실전 안전선

- `C:\stock_bot\config\captain2_off.flag`가 있으면 실주문은 꺼진다.
- Codex 검증은 mock·과거 데이터·주문 0 환경에서만 수행한다.
- 월요일 실계좌 활성화는 사용자가 장전 점검 결과를 확인한 뒤 직접 한다.
- 손익 검증에는 수수료·세금·호가 스프레드·슬리피지가 필요하며, 이번 1주 시험 연결 자체는 수익 보장을 뜻하지 않는다.
