# 주식공통 4 — 고저폭 TOP30 관찰 후보

## 목적

전날까지 확정된 자료로 매일 1~30위 관찰 후보를 만들고, 장중에는 기존
실시간 시세를 읽어 저점·고점·거래대금을 보여준다. 모든 전략이 같은 후보표를
볼 수 있지만 매수 여부는 각 전략의 고유 매수조건이 결정한다.

## 공통 선별조건

| 구분 | 조건 | 계산식·단위 |
|---|---:|---|
| 가격 | 전일 종가 10,000원 이상 | `close >= 10,000` |
| 하루 고저폭 | 10% 이상 | `(고가 / 저가 - 1) × 100` |
| 하루 거래대금 | 100억원 이상 | EOD `value / 100` |
| 후보 수 | 최대 30종목 | 조건 통과 수가 적으면 억지로 채우지 않음 |
| 데이터 시점 | 전날 종가까지 | 당일 미래 고가·저가 사용 금지 |

## 단계와 왕관

| 단계 | 조건 | 의미 |
|---|---|---|
| 👑고저폭 핵심확인대 | 5일 이상 연속 + 최근 5일 평균 거래대금 500억원 이상 | 월요일부터 주문 0 집중 관찰 |
| 확인대 | 5일 이상 연속 | 반복성은 높지만 평균 거래대금 500억원 미만 |
| 선발대 | 3~4일 연속 | 초기에 발견하기 위한 후보 |
| 신규대 | 1~2일 연속 | 새로 강하게 움직이기 시작한 후보 |

## 순위

1. 단계: 핵심확인대 → 확인대 → 선발대 → 신규대
2. 연속 발생일 내림차순
3. 최근 5일 평균 고저폭 내림차순
4. 최근 5일 최소 고저폭 내림차순
5. 최근 5일 평균 거래대금 내림차순

## 장중 표시

| 항목 | 설명 |
|---|---|
| 현재가·전일대비 | 기존 `live_micro_snapshot.json` 읽기전용 시세 |
| 오늘 저점·저점시각 | 관찰기가 09:00 이후 실제로 받은 가격의 최저점 |
| 저점대비 | 현재가가 관찰 저점에서 얼마나 반등했는지 |
| 오늘 고점·고점시각 | 관찰기가 09:00 이후 실제로 받은 가격의 최고점 |
| 실시간 거래대금 | 방향별 실체결 대금 합계, 없으면 현재가×누적거래량 |
| 체결강도·매수비 | 기존 실시간 스냅샷 표시값 |
| LIVE/WAIT/STALE | 15초 이내 당일자료/장전·장후/누락·오래된 자료 |

## 출력 파일

- `data/common_high_range_top30.json`: 전략이 읽을 수 있는 공통 후보
- `data/common_high_range_top30.csv`: 사람이 보는 선별조건 결과표
- `IPC/micro_watch_high_range.json`: 실시간 시세 구독 요청, 주문과 무관
- `data/common_high_range_live_state.json`: 당일 저점·고점 상태
- `data/high_range_crown_shadow_YYYYMMDD.csv`: 👑 후보 1분 간격 주문 0 관찰기록
- `바탕화면/고저폭_왕관후보.html`: 3초 자동 새로고침 화면

## 안전 불변조건

- 실계좌 주문·모의주문·매수·매도 호출 0
- 각 전략의 기존 매수조건·상승보유·매도조건 변경 0
- 미래 고가·저가 사용 0
- 실시간 자료가 누락되면 `STALE`로 표시하고 값을 만들어내지 않음
