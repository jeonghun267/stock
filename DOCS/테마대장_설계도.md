**조합 (09:08 기준 · 246일)**
```
시가대비 +4% + 대금 20억 + 갱신율 35%  →  대장률 67.7%  (14.7배)
```

**★용어 정의 (엔진 배선 시 그대로)**
```
시가 대비 상승률 = (현재가 / 09:00 시가 - 1) × 100
                  ※ "전일종가 대비 등락률"이 아니다! 완전히 다른 값이다.

고가 갱신율     = 09:00부터 지금까지 1분봉 중, 직전 최고가를 넘긴 봉의 개수 ÷ 전체 봉 개수 × 100
                  → 되돌림 없이 계속 신고가를 만드는가 = 매수자가 계속 밀어올리는가

양봉 비율       = 09:00부터 지금까지 1분봉 중, 종가 > 시가인 봉의 개수 ÷ 전체 봉 개수 × 100
                  → 봉마다 매수가 이기는가

거래대금       = Σ(1분봉 거래량 × 종가) / 1e8  (억 단위)
분당 대금      = 직전 3개 1분봉 대금 평균
```

## 5. 🚨 오늘 배운 것 — 반복하면 안 되는 실수

### 5-1. ★승자 vs 패자 비교의 함정 (오늘 3번 당함)

> **오늘 오른 놈**과 **오늘 내린 놈**을 갈라놓고 비교하면 **항상 차이가 나 보인다.**
> 승자는 이미 이겼으니까. **그건 원인이 아니라 결과다.**
>
> **반드시 "진입 시점 기준 전수 백테"로만 판정할 것.**

| 시가 지키기 | 이탈 4.1회 vs 9.6회 | **대장률 9% vs 8% — 차이 없음** |

### 5-2. ★프레임을 엔진과 일치시킬 것

- **창**: 09:00~09:30. 40분·60분으로 늘리면 안 된다.
- **"시가 대비"와 "전일종가 대비"는 완전히 다른 값이다.**
- **12:30까지의 등락률로 잰 신호는 09:06에 쓸 수 없다** (7/14 낮에 이 함정에 빠짐)

### 5-3. ★평균으로 기각하지 말 것 (단, 표본을 확인할 것)

- 8건·11건짜리 표본으로 세운 결론이 **오늘만 3번 깨졌다.**
- 좋아 보이는 교집합(N=10~20)은 **배선하지 말 것.**
