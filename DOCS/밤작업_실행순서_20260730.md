`_run_hidden.vbs`(6/12 제작)가 **이미 이 프로젝트에 있고 28개 태스크가 쓰고 있다.**

### 창이 뜨는 것 = 약 30개, 원인 4종류

| 원인 | 개수 | 해법 |
|---|---|---|
| `cmd.exe /c *.cmd` | 18 | vbs 래퍼 |
| `.cmd` 직접 실행 | 7 | vbs 래퍼 |
| `python.exe` (w 없음) | 5 | **`pythonw.exe` 로 한 글자만** |
| `powershell` Hidden 없음 | 1 | `-WindowStyle Hidden` 추가 (PIPELINE_0900) |

`pythonw.exe` 쓰는 것들은 이미 안 뜬다.

### ⚠️ 함정 — `_run_hidden.vbs` 는 기다리지 않는다

```vbscript
sh.Run "cmd /c ""..."" ", 0, False      ' ← False = 비동기
```

태스크가 **즉시 완료로 끝나고 프로세스만 남는다.** 두 곳에서 사고가 난다.

1. **반복 태스크의 `IgnoreNew` 무력화** — 수칙 "반복태스크+IgnoreNew는 종료여유 60초"가 깨진다.
   태스크가 즉시 끝나니 이전 작업이 도는 중에 다음 게 또 뜬다. (`S05_SIGNAL_GUARD`·`MONEYFLOW_WATCH`)
2. **워치독 오판** — 전략 LIVE는 장중 내내 도는데 태스크는 즉시 끝나므로 "안 돌고 있다"로 볼 수 있다.

### 해법 — 기다리는 형제를 하나 더 만든다

**기존 `_run_hidden.vbs` 는 절대 건드리지 않는다** (28개가 비동기 동작에 의존 중).

```vbscript
' C:\stock_bot\RUN\_run_hidden_wait.vbs   [2026-07-30]
' 기존 _run_hidden.vbs 와 같지만 마지막 인자만 True = 끝날 때까지 기다림.
' 반복 태스크(IgnoreNew 필요)·워치독 감시 대상에 쓴다.
Set sh = CreateObject("WScript.Shell")
If WScript.Arguments.Count >= 1 Then
    sh.Run "cmd /c """ & WScript.Arguments(0) & """", 0, True
End If
```
