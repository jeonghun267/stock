# 2026-08-11 S02 실전 후보 조건과 생산 리플레이 불일치 복구

## 문제 정의
어제 이후 추가한 S02 매도 후보 조건이 실전 런처에서 켜진 채 기존 생산 감사자료와 충돌해, 현재 코드의 생산 리플레이가 FAIL했다.

## 접근법
1. 어제 S02 실제 감사자료를 현재 생산 엔진과 실전 환경 옵션으로 재생한다.
2. 불일치를 ACTION과 REASON으로 분리하고 새 6초 확인 및 오후 약손실 조건과 대조한다.
3. 검증되지 않은 조건은 삭제하지 않고 생산 프로필과 실전 런처에서 OFF로 돌린다.
4. 후보 로직 단위검사와 실전 OFF 배선 검사를 실행한다.
5. 그림자 파일을 제외한 실제 S02 감사자료 전체를 현재 생산 경로로 다시 재생해 불일치 0을 확인한다.

## 하지 않은 것과 이유
- 리플레이의 PASS 판정을 느슨하게 바꾸지 않았다. 이유: 변경된 행동을 허용하면 생산 판단 불일치를 숨겨 실전 게이트가 무의미해진다.
- 새 조건을 삭제하지 않았다. 이유: 그림자 자료를 새 코드 해시로 확보한 뒤 다시 검증할 후보이기 때문이다.
- S02_DAYGATE는 끄지 않았다. 이유: 2026-08-08 사용자가 화요일부터 켜도록 승인한 별도 신규매수 게이트이며 이번 매도 리플레이 충돌 원인이 아니다.

## 재사용 규칙
후보 매매조건을 추가할 때는 기본값과 실전 런처를 OFF로 유지하고, 현재 코드 해시의 생산 리플레이가 통과한 뒤에만 ON으로 전환하라.
