# 2026-07-27 장중 베이스 돌파를 놓친 원인은 매수식보다 늦은 실시간 후보 유입과 독립 전략 부재였다

## 접근법
1. 445090의 micro rank·통합후보·1초 스냅샷 시각을 대조해 최초 감지가 13:15 이후였음을 확인했다.
2. S01~S04 진입시간과 매수 목적을 대조해 장중 횡보 상단돌파를 담당하는 독립 전략이 없음을 확인했다.
3. 캡틴2 BASE의 30봉·3%·6배·10분 리테스트와 90초 실제저점·60초 매수우위 근거를 추출했다.
4. S05 신호·계약·공통회전을 분리하고 기존 공통 보유·매도·6슬롯·중복방지·주문복구에 연결했다.
5. 당일 활동주 중 코스닥·1만원 이상 종목을 주문능력 0 감시파일로 발행해 445090를 장초반부터 구독하도록 했다.
6. 합성 445090 재생, 예약작업 맥락, 기존 전략 회귀 115개, OFF·승인 없음·주문시도 0을 검증했다.

## 하지 않은 것 + 이유
- 기존 S01~S04의 시간이나 매수조건은 넓히지 않음. 이유: 검증된 전략 의미를 바꾸고 사용자 모르게 기존 동작을 변경하게 된다.
- 돌파봉 즉시 추격매수는 넣지 않음. 이유: 기존 26일 검증에서 추격 설정은 음수였고 리테스트 경로만 PF 1.18 근거가 있었다.
- 브로커를 장중 재시작하지 않음. 이유: 새 감시 우선순위는 다음 정상 기동부터 반영해도 되며 장중 공용 실시간 연결을 흔드는 위험이 더 크다.
- S05 승인 파일을 만들거나 OFF 플래그를 해제하지 않음. 이유: 전략 추가 검증은 mock/dry-run 범위이고 실계좌 권한 변경은 사용자 명시 승인 대상이다.

## 재사용 규칙
새 장중 전략을 추가할 때는 매수식뿐 아니라 후보가 신호 전에 실시간 구독되는지, 독립 시간창이 있는지, OFF 상태 예약작업에서 주문시도 0인지까지 함께 검증하라.
