# 2026-07-26 장초반 급상승 신호가 불완전한 체결흐름 구간으로도 매수 준비가 되던 문제

## 접근법
1. 전략 01 매수판정과 신호 생성부에서 각 조건의 실제 관측 구간을 추적한다.
2. 공개 시장미시구조 연구와 KRX 개장 체결 방식을 확인해 주문흐름·호가·유동성 보완 후보를 분리한다.
3. 누적 매수·매도대금 비율의 실제 시작·종료 시각 차이를 계산해 5초 미만이면 워밍업으로 대기시킨다.
4. 기존 실시간 호가에서 총잔량 매수비중·스프레드·마이크로프라이스 편향을 계산해 신호 로그에만 기록한다.
5. 전략 01 전체 회귀와 임시 신호 런타임을 실행해 6회·중복방지·공통청산 유지와 주문 0건을 검증한다.

## 하지 않은 것 + 이유
- 호가 불균형이나 스프레드를 즉시 필수 매수조건으로 만들지 않음. 이유: 종목별 호가 필드 누락 가능성과 충분한 장중 재생 표본이 없어 검증되지 않은 임계값이 정상 신호를 막을 수 있다.
- 공개 자료를 헤지펀드의 비공개 운영 규칙이라고 표현하지 않음. 이유: 확인 가능한 것은 논문과 거래소 규정뿐이다.
- 공통 상승보유·매도·주문·6슬롯 엔진은 수정하지 않음. 이유: 요청 범위는 전략 01 매수 신호 보완이다.

## 재사용 규칙
짧은 구간 누적흐름으로 진입할 때는 비율 값뿐 아니라 실제 관측시간을 함께 전달해 최소 창이 완성된 뒤에만 판단하라.
