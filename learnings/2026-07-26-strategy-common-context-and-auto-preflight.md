# [2026-07-26] 공통 후보 컨텍스트와 조건부 자동실전

## 문제 한 줄
분리 전략의 매수식을 바꾸지 않으면서 캡틴 돈맥·머니플로우·특별전략 후보를 공유하고, 구형 엔진과 중복 없이 다음 거래일 S03만 자동 활성화해야 했다.

## 접근법
1. 브로커의 실제 `micro_watch*.json` 우선순위와 200종목 결과를 먼저 재현해, 돈맥 170개 중 169개와 고저폭 TOP30 전부가 이미 실시간 구독되는지 확인했다.
2. 주문·브로커 import가 없는 공통 후보 발행기를 만들고, 오늘자 소스만 기존 EOD 적격 풀에 합쳤다.
3. S01·S02는 공통 후보 합집합을 읽게 하고, S03은 기존 골짜기 풀을 확대하지 않은 채 소스 겹침만 기록했다.
4. 구형 골짜기 OFF·예약 Disabled·빈 장부, S03 빈 상태, 오늘자 네 소스, 정확 최우선호가, 계좌 잔고와 전체 미체결을 읽기 전용으로 확인하는 사전점검을 만들었다.
5. 모든 점검 통과 뒤에만 승인파일을 원자적으로 만들고 S03 OFF를 제거하며, LIVE 게이트는 그 결과가 나오기 전에는 공통 회전엔진을 시작하지 않게 했다.
6. 단위검사, 주말 dry-run, 실제 예약 실행, S01·S02·S03·공통 회귀를 각각 분리해 검증했다.

## 하지 않은 것 + 이유
- 브로커 `MICRO_CAP=200`을 늘리지 않았다. 이유: 현재 실제 합집합에서 필요한 돈맥·고저폭 후보가 거의 모두 포함됐고, 실시간 등록 부하를 승인 없이 바꿀 근거가 없었다.
- 고저폭 왕관이나 머니플로우 순위를 새 매수조건으로 넣지 않았다. 이유: 사용자는 자료 연결을 요청했지 기존 전략별 매수 계산식 변경을 승인하지 않았다.
- S03 골짜기 풀을 돈맥 전체로 확대하지 않았다. 이유: 전일 거래대금·시가총액 등 S03의 확정 후보 계약을 우회하게 된다.
- 사전점검 실패 때 SHADOW 회전엔진을 시작하지 않았다. 이유: 09:00 뒤 신호를 그림자 포지션으로 먼저 소비하면 뒤늦은 실전 승격 시 실제 진입을 놓칠 수 있다.

## 재사용 규칙
실전 전략에 외부 선별 자료를 연결할 때는 후보 컨텍스트와 매수판정을 분리하고, 자동승격은 “읽기 전용 계좌대조 → 최신 데이터 계약 확인 → 승인 생성 → OFF 제거 → 엔진 시작” 순서로만 수행하라.
