# 2026-07-25 골짜기 오전 매도를 공통엔진과 같은 09:30 종료선으로 비교

## 접근법
1. `memory.md`와 현재 골짜기 설정을 확인해 MORNING_CRASH의 신규매수 종료가 09:20, 최종청산이 09:30임을 고정했다.
2. 오후 BASE_BREAKOUT 6건은 비교 범위가 아니며, 과거 오전 2건에는 현재 규칙 재생에 필요한 1초 FID15 자료가 없음을 확인했다.
3. 현재 골짜기 파일을 수정하지 않고, 같은 MORNING_CRASH 진입만 읽는 독립 주문 0 관찰기를 만들었다.
4. 공통엔진의 BASE 매도판정을 실행하되 미청산이면 09:30에 종료 신호만 기록하도록 제한했다.
5. KST 필수 계약 실패를 `Asia/Seoul` 명시로 한 번 수정한 뒤 단위검사·구문검사·주문호출 정적검사·예약작업 상태를 재검증했다.

## 하지 않은 것 + 이유
- `valley_hunter_live_v1.py`와 기존 골짜기 예약작업은 수정하지 않음. 이유: 비교 관찰 때문에 현재 매수·매도 동작이 달라지면 A/B 자체가 무효가 된다.
- 오후 BASE_BREAKOUT 결과와 과거 오전 2건을 현재 골짜기 성과로 사용하지 않음. 이유: 시간창과 규칙이 다르고 정확한 초단위 흐름도 없다.
- 실계좌 매도 주문은 보내지 않음. 이유: 비교 단계는 신호가와 비용 전 손익을 기록하는 주문 0 관찰로 충분하다.

## 재사용 규칙
매도방식을 비교할 때는 같은 진입과 같은 최종 보유시각을 먼저 고정하고, 기존 전략을 건드리지 않는 병렬 주문 0 관찰기로 비교하라.
