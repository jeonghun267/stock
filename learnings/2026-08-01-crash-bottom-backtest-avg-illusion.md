# [2026-08-01] 급락 저점매수 백테 평균 +0.10%가 상위 3건이 만든 착시였다 (빼면 -0.63%)

## 접근법
1. 고저폭30 유니버스를 일봉으로 복원하고 실제 선정본(7/31 그림자 30종목)과 대조해 30/30 일치를 확인한 뒤에만 진행
2. 3분봉 오염 필터 3종(①120봉↑ ②일봉 대비 시고저종 5% 이내 ③첫봉 09:03 이전)을 통과한 281 종목일만 사용
3. 문턱(-8/-10/-12/-14) × 매도 3안(익절→당일종가 / 익절→익일시가 / 전량 익일시가) 전수 실행, 비용 0.4% 차감
4. 평균이 플러스로 나오자 곧바로 착시 검사 3종 실행: 상위 3건 기여도 / 월별 분해 / 전·후반 분할검증
5. 상위 3건 기여 +64.9%p vs 전체 합 +9.1%p → 착시 판정. 6월 -2.85% / 7월 +3.06%, 분할검증 불합격으로 확정
6. "중간 회복이 있지 않냐"는 질문에는 MFE(진입 후 최대 반등)를 실측 — 평균 +4.4% 반등이 있지만 어떤 익절(+3/5/7/10%·트레일)로 잡아도 종가 매도보다 못함을 확인

## 하지 않은 것 + 이유
- 조건을 더 추가해 성적을 끌어올리는 격자 탐색은 하지 않음. 이유: 표본 91건에서 조건을 더하면 과최적화가 되고, 7/31 전수에서 "확인 조건을 더할수록 나빠진다"가 이미 실증됨
- 매도 규칙 개선으로 살리려는 시도를 더 밀지 않음. 이유: 모든 매도 방식(종가·익절 4종·트레일 2종·익일시가)이 본전 이하 = 문제는 신호 품질이라는 7/27 S02 교훈과 동일 패턴
- 시장 전체 유니버스 백테는 하지 않음. 이유: 질문의 유니버스가 고저폭30으로 명시돼 있고, 8/1 오전에 유니버스를 잘못 잡아 헛보고한 전례가 있음
