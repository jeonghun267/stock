# 2026-07-27 전략 2의 순간 반등 오진을 막고 장중 안전 재기동

## 접근법
1. 실제 회전 상태와 체결 이력을 읽어 수익·손실·재진입을 종목별로 분리한다.
2. 신규 매수를 OFF 플래그로 차단하되 보유 매도와 체결복구 경로는 유지한다.
3. 손실 진입과 신호 코드를 대조해 누적 호가만 보고 즉시 진입하는 결손을 찾는다.
4. 최우선 매수·매도호가, 스프레드, 마이크로프라이스, 최우선 매수잔량 비율을 필수 입력으로 추가한다.
5. 같은 바닥 앵커에서 2초·3관측 연속 회복과 추격가격 상한을 통과한 뒤에만 BUY_READY를 발행한다.
6. 전략 2의 하루 서로 다른 종목 한도만 15로 늘리고 공용 6슬롯과 종목당 2회는 유지한다.
7. OFF 상태에서 컴파일·단위·회귀·신호전용 주문 0 검사를 통과한 뒤 신호기와 회전엔진을 재기동한다.
8. 오늘 통합 사전점검 PASS와 승인 파일을 재확인한 뒤 OFF만 해제하고 heartbeat·주문시도·중계표시를 검증한다.

## 하지 않은 것 + 이유
- 공통 매도엔진은 수정하지 않음. 이유: 당일 손실의 직접 증거는 매도보다 순간 반등을 즉시 매수한 진입 결손에 있었고, 다른 전략의 청산 동작을 함께 바꾸면 원인 추적이 불가능해진다.
- 공용 슬롯을 15로 늘리지 않음. 이유: 15는 하루 서로 다른 종목 기회 수이고 동시 보유 한도는 기존 6슬롯이라는 사용자 정의가 분명하다.
- 사전점검 게이트를 우회해 엔진을 직접 실행하지 않음. 이유: 오늘 PASS·승인·OFF 해제라는 기존 안전 계약으로 장중 재기동이 가능했다.

## 재사용 규칙
장중 전략이 빠르게 손실을 반복할 때는 먼저 신규 진입만 잠그고, 실제 손실 진입에서 빠진 미세구조 확인을 추가한 뒤 주문 0 회귀검사와 기존 승인 게이트를 통해 재기동하라.
