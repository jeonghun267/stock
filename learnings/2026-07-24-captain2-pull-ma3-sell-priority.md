# 2026-07-24 캡틴2 PULL 상승보유가 정상 상승은 지키면서 매도장악에는 빠져나오게 하는 우선순위

## 접근법
1. `_hold_or_sell`의 실제 실행순서를 따라 하드컷·강제청산·MA3·트레일·돈마름·점수·흐름매도의 우선순위를 확인한다.
2. 기존 MA3 허가가 RAID에서 일반 전략매도를 전부 조기 반환으로 잠그는 구조임을 확인한다.
3. PULL에 MA3 허가를 연결하되 RAID 분기는 그대로 두고, 기존 임계값인 최근60초 매수비 48% 이하·직전5초 저점붕괴·비가속·15초 지속만 PULL 예외매도로 사용한다.
4. 하드컷과 15:10 청산을 MA3보다 위에 그대로 유지하고, MA3 해제 후에는 기존 매도판정으로 자연스럽게 복귀시킨다.
5. PULL 정상상승·매도우위만 존재·3조건 15초 지속·재가속 회복·RAID 무변경·MA3 해제·하드컷 우선의 7개 상태전이를 독립 검증한다.

## 하지 않은 것 + 이유
- RAID의 기존 MA3 보유 동작은 바꾸지 않음. 이유: 사용자가 한 전략씩 수정하라고 했고 이번 범위는 PULL 상승보유 완성이었다.
- 새로운 매수비율·시간 임계값은 만들지 않음. 이유: 이미 운용 중인 48%·15초·5초 구조붕괴 조건을 재사용해야 원인 추적이 가능하다.
- MA20 이탈만으로 즉시 매도하지 않음. 이유: MA3 허가만 해제하고 기존 돈·가격 구조 매도조건이 다시 판단하도록 하는 것이 정상 눌림 오매도를 줄인다.
