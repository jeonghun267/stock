# [2026-07-24] 골짜기가 6왕복 전부 체결하고 +910원 벌었는데 저녁정산은 "체결 0"으로 오보한 원인 = 정산이 로그에 존재하지 않는 문구를 세고 있었음

## 접근법
1. 정산 파일의 "매수시도 8 · 매수체결 0"과 원본 로그를 직접 대조 → 로그엔 체결확인·주문번호 확정이 명백히 존재 (숫자 모순 확정)
2. 정산 스크립트에서 집계 부분을 grep → "✅매수체결"이라는 문자열을 셈
3. 실제 로그의 체결 라인 문구를 확인 → "✅체결확인"(매수) / "✅매도 체결확인"(매도) — 정산이 찾는 문구는 어디에도 없음
4. 시도 집계의 "🔥" 휴리스틱도 검증 → 세션 배너(🏔️🔥)까지 세서 시도 수가 부풀려짐(재기동마다 +1)
5. 실제 문구로 교체 후 어제 로그로 재집계 실행 → 관망1·시도6·체결6·매도6 = 실거래와 일치 확인

## 하지 않은 것 + 이유
- 정산에 골짜기 손익 합계 추가는 하지 않음. 이유: 승인 범위는 집계 오보 수정뿐 — 지시받은 것만 배선. 손익 표시는 원하면 별도 제안
- "매도 체결확인"을 "체결확인" 포함으로 뭉뚱그려 세지 않음. 이유: "✅매도 체결확인"에 "체결확인"이 부분 문자열로 들어 있어 매수/매도가 섞임 — 접두 이모지까지 포함한 정확한 문구로 분리
