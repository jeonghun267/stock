# 2026-07-24 골짜기 Gate1 저유동성 확대 시 실시간 체결 누락 없이 안전하게 고정풀을 구독하는 문제

## 접근법
1. 이전 작업 대화와 memory.md를 대조해 승인 범위를 Gate1 09:00~09:20으로 복원한다.
2. 전일대금 하한과 시총 하한을 Gate2와 분리해 장전 감시풀에만 적용한다.
3. 08:50 발행 파일에 오늘 날짜를 기록하고 broker 최우선 순서로 전체 풀을 분할 구독한다.
4. 장전 고정풀 전체를 추적하되 전일종가 대비 -4% 이하에서만 Gate1을 무장한다.
5. FID15 방향별 체결 누락을 fail-closed로 연결하고 최신 EOD 독립 필터와 행동검사로 검증한다.
6. 합성 한글이 셸 인코딩에서 깨진 실패는 유니코드 이스케이프 입력으로 원인과 제품 로직을 분리해 재검증한다.

## 하지 않은 것 + 이유
- Gate2의 700억원 하한과 09:30 이후 정렬은 변경하지 않음. 이유: 승인 범위가 장전 Gate1 고정풀로 한정됐고 기존 전략의 후보 품질을 바꿀 근거가 없었다.
- 시가 갭상승률을 별도 진입조건으로 사용하지 않음. 이유: 골짜기의 사용자 확정 조건은 전일종가 대비 -4% 이하이며 별도 갭상승 보조조건은 범위를 벗어났다.
- 실시간 등록 누락 종목을 지연 데이터로 대체하지 않음. 이유: FID15 방향별 실체결이 없으면 FAST의 매수우위 판단 자체가 성립하지 않는다.

## 재사용 규칙
감시 유니버스를 넓힐 때는 후보 필터와 실시간 구독을 같은 오늘자 전용 파일로 묶고, 필수 실시간 FID가 없으면 진입을 fail-closed하라.
