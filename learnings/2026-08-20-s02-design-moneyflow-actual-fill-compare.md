# 2026-08-20 S02 새 저점 설계와 돈맥을 실제 S02 체결에 같은 기준으로 비교하기

## 접근법
1. 저장된 S02 신호에 당시 장세·시가·전일종가·최근 변동폭을 결합한다.
2. 새 설계의 FAST/RETEST 가격상한과 돈맥의 -5%·저점+1.5~3% 프록시를 각각 판정한다.
3. 전략2 엔진 로그의 소유권과 브로커 체결 CSV의 시각·코드·수량을 대조한다.
4. 실제 매수 8건과 하드스톱 4건을 각 후보 규칙이 샀을지 차단했을지 집계한다.
5. 돈맥 실거래는 이벤트 저널과 브로커 체결을 대조하고, FLATACCT 선매도로 성과 귀속이 깨진 경우 미검증으로 남긴다.

## 하지 않은 것 + 이유
- 돈맥 전체 조건을 재구현하지 않음. 이유: 돈유입·3연속 양봉의 정확한 생산 결정 입력이 보존되지 않아 깊이·가격창 프록시 이상은 생산 재생이 아니기 때문이다.
- 열린 S02 포지션을 수익 또는 손실로 결론내리지 않음. 이유: 2026-08-20 장중 미완성 상태이기 때문이다.

## 재사용 규칙
전략 비교에 실제 체결을 사용할 때는 전략 로그로 소유권을 정하고 브로커 체결로 가격·수량을 확정하며, 보존되지 않은 조건은 프록시로 명시하라.
