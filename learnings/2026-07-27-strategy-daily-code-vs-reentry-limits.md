# 2026-07-27 전략별 종목 수 한도와 동일 종목 재진입 한도가 하나의 `6회` 설정으로 혼동됐다

## 접근법
1. 회전 엔진·전략별 신호·실행 CMD·테스트·운영 문서에서 `6회`와 `1회` 표현을 전부 검색했다.
2. 전략 상태를 `당일 진입한 서로 다른 종목 목록`과 `종목별 완료 회전 수`로 분리했다.
3. 신규 종목은 전략별 6개에서 차단하고, 기존 종목은 매도 완료와 새 신호 뒤 2회에서 차단하도록 독립 조건을 적용했다.
4. 6종목을 순차 회전한 뒤 7번째 종목 차단, 동일 종목 1차 매도 뒤 2차 진입 허용, 3번째 진입 차단을 각각 모의검사했다.
5. 전략 1~4의 실제 설정값과 실행 CMD를 대조하고 전체 전략 회귀검사와 공용 슬롯 동시성 검사를 실행했다.

## 하지 않은 것 + 이유
- 공용 6슬롯을 전략별 일일 6종목 한도로 재사용하지 않음. 이유: 슬롯은 동시 보유 제한이고 일일 종목 수는 매도 뒤에도 유지돼야 하는 별도 상태다.
- 활성 포지션에 도착한 두 번째 신호를 소비하지 않음. 이유: 첫 포지션 종료 뒤 새 기회를 허용해야 하지만 동시에 두 주문을 내면 안 되기 때문이다.
- 전략 4 승인 파일을 점검 전에 만들지 않음. 이유: 사용자 승인은 오늘 한정이지만 사전점검 전항목 통과가 선행 조건이다.

## 재사용 규칙
`횟수`가 종목 수·동시 슬롯·재진입 수 중 무엇인지 구분해야 할 때는 각각 별도 상태와 독립 차단 테스트로 고정하라.
