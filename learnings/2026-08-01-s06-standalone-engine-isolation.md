# [2026-08-01] 신규 전략(S06 급락저점추격·10슬롯·밤넘김)을 공용 체계에 안 태우고 독립 엔진으로 만든 이유

## 접근법
1. 공용 기반(strategy_common_foundation_v1)을 먼저 읽음 → SafetyLimits가 6슬롯·1주·200만원에 하드고정(어기면 예외)임을 확인
2. shared_slots.py를 읽음 → 전 전략이 나눠 쓰는 공용 6칸 장부라서, 새 전략이 acquire하면 S01~S05 슬롯을 잠식함을 확인
3. 공용코어(strategy_01_rotation_engine_v2, 1,521줄)를 전부 읽고 주문 제출·체결 확인·취소·복구(RECOVERY_BLOCKED) 절차를 새 파일에 그대로 복사
4. 매도가 "종가매수 방식(당일 +10% 익절, 미도달 시 익일 09:01~09:10 매도)"으로 확정되자 공동매도 라이브러리 연결을 제거하고 매도 2줄만 남김
5. 날짜 넘김을 위해 상태 로드 규칙을 변경: HOLD는 밤을 넘겨도 정상, 주문이 걸린 채(PENDING류) 날짜가 바뀐 것만 잠금
6. 단위테스트 8건(발동·계단리셋·포기선·관찰보류·익절·무손절보유·익일매도·하루1회) + 그림자 스모크(--once)로 검증

## 하지 않은 것 + 이유
- 공용코어에 S06을 편입하지 않음. 이유: 6슬롯 하드락 + 15:10 강제청산이 밤넘김과 충돌 + 8/3(월)이 개편된 1·2·3번의 첫 실전이라 공용 파일은 한 줄도 건드리면 안 되는 시점
- 기존 종가매수(EOD_GAP)의 포지션 파일에 끼워 넣지 않음. 이유: 그쪽 매도경로는 모의 OPEN을 실매도 주문하는 미해결 문제(7/29 점검)가 있어 외부 주입은 지뢰
- 공동매도의 StrategyId 열거형에 S06을 추가하지 않음. 이유: 살아있는 공용 파일 수정이며, 최종 매도 규칙이 공동매도를 아예 안 쓰는 것으로 확정됨
- 하드손절 추가하지 않음. 이유: "매도 손대지 마" 지시 + 1주 소액 테스트라 밤사이 위험 상한이 낮음

## 재사용 규칙
새 전략을 붙일 때는 코드를 쓰기 전에 공용 기반의 하드락(슬롯·수량·자본)과 공유 자원(슬롯 장부·포지션 파일)을 먼저 읽고, 하나라도 충돌하면 독립 엔진 + 공용코어 절차 복사로 가라.
