# stock — 아빠 프로젝트

키움증권 OpenAPI 기반 국내주식 자동매매 시스템 (SAFEPLUS).

## 구조

| 폴더 | 내용 |
|---|---|
| `RUN/` | 실전 엔진·수집기·워치독 (브로커 게이트웨이, 캡틴2 돈흐름 엔진, 골짜기 사냥꾼 등) |
| `CORE/` | 공용 모듈·수집 유틸 |
| `DOCS/` | 설계 문서·태스크 XML 백업·베이스라인 스냅샷 |
| `learnings/` | 문제 해결 과정 학습 노트 |
| `config/` | 설정 (`secrets.ps1`은 비추적 — 계좌번호 등 민감값) |

## 캡틴2 전략

- 전략 번호와 현재 연결 상태: [`DOCS/캡틴2_전략목록.md`](DOCS/캡틴2_전략목록.md)

## 주의

- `data/` `LOG/` `IPC/` 등 런타임 데이터는 추적하지 않음 (.gitignore).
- 계좌번호·비밀값은 `config/secrets.ps1`(비추적)에서 환경변수로 주입됨.
- 32bit 파이썬(`C:\Python310-32`)은 키움 OCX 브로커 전용, 64bit(`C:\python310`)는 엔진용.
