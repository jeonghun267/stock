## 0. 친구님 지시 원문

> "급행도 꺼 두개만 남겨"
> "2번으로 해 급행 끄고 822행도 없애"
> "지금 수정할거야"

2안 = **급행 경로를 없애되, 822행(`DEEP_ZONE_EXPRESS_ONLY`)도 같이 없애서
계단(4단계) 경로가 −8%보다 깊은 구역까지 들어가게 한다.**

최종 목표 상태: S03 레인은 **계단(OPEN_CRASH) + 급락(INTRADAY_CRASH) 두 개만**.

## 1. ⚠️ 먼저 읽을 것 — 장중 수정이다

- 지금은 **장중(10:10)**이고 `CLAUDE.local.md` 규칙 1은 08:40~15:30 실전파일 편집 금지다.
  친구님이 그 자리에서 명시 지시했으므로 예외로 집행한다.
- **파일을 고쳐도 이미 떠 있는 프로세스에는 즉시 반영되지 않는다.**

  ⇒ **테스트를 통과하지 못한 중간 상태로 파일을 남기지 말 것.** 한 번에 끝내거나 원복한다.

## 2. 배경 (실측 확인된 현재 구조)

```
시가 대비  -4% ~ -8%   → 계단(4단계) 경로로 매수
          -8% 아래     → 급행(EXPRESS) 전용   ← 822행이 계단을 막는다
```

급행은 **별도 레인이 아니라 1레인(OPEN_CRASH) 안의 빠른 통과 경로**다.
오늘 레인 집계에도 EXPRESS 항목은 없다 (`EARLY_LOW 61 · OPEN_CRASH 27 · INTRADAY_CRASH 41`).

급행 조건 (`strategy_03_signal_contract_v1.py` 34~37):
```
EXPRESS_DEPTH_PCT       = -7.0    당일 고점 대비 -7% 이상 깊어야 자격
EXPRESS_FAST_DROP_PCT   = -3.0    직전 10분 안에 -3% 이상 '빠른 낙하'
EXPRESS_FAST_WINDOW_SEC = 600     직전 10분
EXPRESS_NEAR_LOW_PCT    = 1.5     저점 +1.5% 안에서만
```

급행이 생긴 이유 (`골짜기_급반등.py` 650~654 주석):
> 8/6 씨어스(458870) 인계 구멍 — S06 감시망에 없는 종목을 −8%에서 넘겼더니 아무도 안 잡았다.

**⇒ 급행만 없애면 −8% 이하가 다시 사각지대가 된다. 그래서 822행을 같이 없애는 것이 2안이다.**

## 4. 판단이 필요한 지점 — 임의로 정하지 말 것

### ① `express_deep` 무장 조건 (골짜기_급반등.py 677~690)
```python
            express_deep = (
                state.day_high > 0
                and (point.price / state.day_high - 1.0) * 100.0 <= EXPRESS_DEPTH_PCT
            )
            if point.price > arm_price and not express_deep:
                return self._row("WAIT", "OPEN_DROP_GT_4PCT", point, profile)
```
이건 **매수가 아니라 "저점 추적 시작(무장)" 조건**이다.
원 주석의 실증 사례:
> 7/29 376900 시가 28,000 → 33,500 급등 → −15% 폭락 — 시가 기준으론 무장 불가라
> 급행이 원천 봉쇄됐다

- **유지(권고)**: 시가 위에서 급등 후 폭락한 종목도 무장 → 822행이 사라졌으므로 **계단이 직접 잡는다.**
  2안의 취지("깊은 곳도 계단이 커버")와 맞는다. 이름만 `deep_arm` 등으로 바꾸면 된다.
- **제거**: 시가 대비 −4% 밴드에 들어온 종목만 무장. 7/29 376900 유형은 놓친다.

**⇒ 권고는 "유지 + 이름 변경". 친구님 확인 후 집행할 것.**

### ② handoff 잔재 정리를 이번에 같이 할지
`handoff_to_s06` 관련 잔재 (373·446~447·620·1087·1093행)는 **판정에 안 쓰이는 이름뿐인 유산**이다.
친구님이 "이런 역할이 여기 있으면 안 되는 거 아니니?"라고 지적한 대상.
- 같이 지우면 diff가 커지고 장중 위험이 올라간다.
- **권고: 이번엔 822행만 손대고, 잔재 정리는 마감 후 별건으로.**
