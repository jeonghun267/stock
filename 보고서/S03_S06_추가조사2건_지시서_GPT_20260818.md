## 조사 1. 기준점 불일치 — 두 구간이 겹치거나 비는 날이 있는가

### 왜 묻는가

1차 보고는 "S03 는 -4%~-8%, S06 은 -8% 이상이라 안 겹친다"고 결론냈다.
**그런데 두 전략은 낙폭을 서로 다른 기준점에서 잰다.**

```
S03  RUN\strategy_03_signal_contract_v1.py:311
     -8.0 < drop_from_open <= -4.0          ← 시가(open) 대비

S06  RUN\strategy_06_crash_low_chase*.py:194
     S06_DROP_PCT = 8.0                      ← first_price 대비
```

**기준점이 다르면 "안 겹친다"는 결론은 조건부**다. 같은 축에 놓고 비교할 수 없다.

### 문제가 되는 구조 (수치 예시 — 검증 대상)

시가 10,000 → 장중 고점 11,000 (시가 대비 +10%) 인 종목이라면:

```
S03 구간 : 시가 대비 -4% ~ -8%   =  9,600 ~ 9,200
S06 구간 : 고점 대비 -8% 이상    = 10,120 이하

→ 9,600 은 고점 대비 -12.7%
→ S03 구간 전체가 S06 구간 안에 들어간다 = 겹침
```

반대로 **시가가 곧 장중 고점인 날**(개장 직후 바로 하락)에는 두 기준이 같아져 겹치지 않는다.
2026-08-18 의 487400 이 후자였을 가능성이 있다(`first_price 14,880`).

즉 **"시가 이후 얼마나 더 올랐는가"가 겹침 여부를 가른다.**

### 조사할 것

**1-A. `first_price` 의 정의를 코드로 확정하라** ★먼저 할 것

- `first_price` 가 **장중 고점**인가, **관측 시작 시점의 가격**인가, **시가**인가?
- 파일:행 근거를 제시하라. 이것이 확정돼야 나머지 비교가 성립한다.
- ⚠️ Claude 는 이것을 "장중 고점"으로 **추정**했을 뿐 확인하지 못했다. 추정을 인용하지 말고 코드를 보라.

**1-B. 두 구간의 겹침을 수식으로 정리하라**

- 시가를 `O`, S06 기준점을 `P` 라 할 때, `P/O` 비율이 얼마 이상이면 두 구간이 겹치는가?
- 반대로 두 구간 **사이에 사각지대**(어느 전략도 안 잡는 낙폭 구간)가 생기는 조건은?

**1-C. 실제 자료로 빈도를 세라**

- 기간: **최소 10거래일**
- 대상: S03 또는 S06 신호가 난 종목 전부
- 각 종목마다 `시가` / `S06 기준점(first_price)` / `비율` 을 뽑고, 1-B 의 조건에 걸리는 날이
  **며칠 중 몇 건**인지 집계하라.
- 결과를 세 갈래로 분류: **겹침 / 배타 / 사각지대**

**1-D. 겹친 사례가 있었다면 실제로 무슨 일이 있었는가**

- 두 전략이 같은 종목을 같은 구간에서 노린 사례가 실제로 있었는지
- 있었다면 어느 쪽이 먼저 잡았고 결과는 어땠는지

## 조사 2. 슬롯 경합 — `SLOT_FULL` 이 실제로 발생했는가

### 왜 묻는가

1차 보고에서 확인된 사실:

```
RUN\strategy_06_crash_low_chase*.py:27
   "전략 1~5와 shared_slots 6칸을 함께 쓴다. 먼저 조건을 충족한 전략이 슬롯을 가져간다"
:229   raise ValueError("Strategy 06 requires exactly six shared slots")
:1417  if len(self._active_positions()) >= self.config.max_slots:
:1418      self._event("BUY_WAIT", code=code, name=name, reason="SLOT_FULL")
```

**선착순은 명시된 설계이므로 그 자체는 결함이 아니다.**
그러나 **슬롯이 차서 실제로 못 산 사례가 얼마나 되는지는 아무도 모른다.**
그것이 잦다면 "설계대로 동작 중"이어도 **기회 손실의 크기**는 별개로 알아야 한다.

### 조사할 것

**2-A. `SLOT_FULL` 발생 이력 전수**

- 검색 대상: `data\LOG\` 전체 + `data\strategy_06_crash_low_chase\strategy_06_signals_*.csv`
- 검색어: `SLOT_FULL`, `BUY_WAIT`, 그 밖에 슬롯 부족을 뜻하는 이벤트명
  (이벤트명이 전략마다 다를 수 있으니 코드에서 먼저 확인하라)
- 기간: **최소 10거래일**
- 기록할 것: `날짜 / 시각 / 전략 / 종목 / 당시 슬롯을 점유한 전략과 종목`

**2-B. 못 산 종목의 이후 성과**

- `SLOT_FULL` 로 막힌 종목의 **그 시점 → 당일 저점 / 당일 종가** 를 추적
- **"놓친 기회"인지 "피한 손실"인지** 집계하라
- ⚠️ 승자편향 금지 — 전건을 넣어라. 좋아 보이는 사례만 고르지 말 것

**2-C. 슬롯 점유의 전략별 분포**

- 6슬롯을 어느 전략이 얼마나 오래 점유했는가 (전략별 점유 시간 비중)
- 특히 **S01 이 개장 3분에 6종목을 잡는 날**(2026-08-18 실측)에
  다른 전략이 슬롯을 못 쓴 시간이 얼마나 되는가
