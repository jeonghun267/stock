# 선별판 유니버스 확장 — 3단계 설계안 (2026-08-19, 승인 대기)

작성: Claude / 배경: 8/19 돈맥 이익 종목 5개 중 3개가 고저폭판 밖(선별판 전용) — 다른 전략들은 그 종목을 아예 못 봤다. 친구님 질문("돈맥 혼자 보나?")에서 파생.

## 핵심 질문
"S02(저점매수)가 선별판 종목까지 봤다면 더 벌었을까?" — 이걸 실전 위험 0으로 검증한다.

## 전제 사실 [실측 8/19]
- 선별판 = `data\돈흐름_선별판.json` univ_codes 200종목 (당일 낙폭+실시간 수급 기준, 돈맥 전용)
- 고저폭판 = 50종목 (전일 고저폭·거래대금 기준, S01·S02·S03·S06의 뿌리)
- 두 판의 성격이 다르다: 선별판은 "오늘 돈이 몰리는 곳", 고저폭판은 "어제 출렁였던 곳"
- 선례 있음: `strategy_high_range_top5_low_shadow_v1.py`가 S02 생산 판정함수(`저점매수_매도소진.detect_flow_book_exhaustion`)를 import해 주문 0으로 그림자 신호를 만든 전례 — 같은 패턴 재사용 가능

## 1단계 — 소급 기여도 분석 (새 파일 0개, 즉시 가능)

**무엇**: 돈맥 체결 전건(로그에 영구 보존)을 날짜별로 "고저폭판 포함 / 선별판 전용"으로 갈라 손익 기여를 집계. 판 구성은 `high_range_shadow_<날짜>.csv`로 소급 복원 가능 — **14일치 즉시 계산 가능, 자동화·배선 불필요.**

**성공기준**: 선별판 전용 종목의 이익 기여가 5거래일 이상에서 재현되는가 (8/19 하루 3/5는 특수장세일 수 있음).

**중단조건**: 기여가 8/19 하루에만 몰려 있으면 → 확장 근거 소멸, 여기서 종료.

## 2단계 — 교집합 그림자 (새 독립 파일 1개, 주문 0)

**무엇**: top5 그림자와 같은 골격의 새 파일 — 유니버스 = **선별판 − 고저폭판**(고저폭판 밖 종목만), 판정 = **S02 생산 판정함수 그대로 import**(복제 금지), 시세 = `IPC\live_micro_snapshot.json` 파일만 읽기(브로커 IPC 요청 0 — 8/13 사고 재발 방지).

**기록**: 가상신호 시각·가격, +10/30/60분·종가 성과, 비교군 = 같은 날 실제 S02 신호 전건 (비교군 전건 기록 원칙).

**fail-closed**: micro snapshot이 해당 종목을 커버 안 하면 그 종목 관찰 중단+이유 기록 (돈맥이 이미 쓰므로 커버 예상되나 [추정] — 착수 시 실측 확인이 첫 작업).

**성공기준**: 5거래일 집계에서 그림자 신호 성과가 실제 S02 신호와 대등 이상 + 신호 품질(가짜반등률)이 무너지지 않음.

## 3단계 — 실전 배선 (별도 승인, 지금 결정 안 함)

2단계 통과 시에만 논의. 선택지:
- (가) S02 감시 유니버스에 교집합 추가 — S02 생산코드 수정 필요 (동결·검증 절차)
- (나) 돈맥 쪽 확장(진입 상한/예산 증액) — S02는 그대로
- 슬롯 정책 결정 필요: S02 후보 증가 → 공용 6슬롯 경합 심화 + 회전 200만 한도와 충돌 가능

## 반대 의견 (일부러 남김)

1. **근거가 표본 1일**: 8/19는 개장 -3.42%→되돌림의 특수장세 — 선별판(당일 낙폭 기준)에 극도로 유리한 날. 1단계가 이걸 가른다.
2. **돈맥 성공의 원인 분리 안 됨**: 유니버스 덕인지 진입 게이트 덕인지 미분리. 게이트 이식 안건(재검수 대기)과 결과가 얽힐 수 있음 — 두 그림자를 따로 집계할 것.
3. **신호 희석 위험**: S02 문턱은 고저폭 모집단에서 조정된 것 — 다른 모집단(수급 몰림주)에서 같은 성능 보장 없음. 지표·조건 추가는 이 프로젝트 반복 실패 이력(7/31).
4. **부하**: 감시 종목 증가는 판정 루프·스냅샷 부하 증가 — 2단계는 별도 프로세스라 실전 무영향이지만, 3단계(가)는 부하 실측 필요.

## 비용/위험 요약
- 1단계: 위험 0 · 분석 1회
- 2단계: 위험 ≈0 (주문 0·파일 읽기만·독립 프로세스) · 새 파일 1개 + 태스크 1개
- 3단계: 실전 위험 있음 — 2단계 증거 없이는 착수 금지
