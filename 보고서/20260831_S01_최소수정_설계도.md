## 작업 C — PROFIT_TRAIL 진단 (3순위, **이번엔 보고만**)

### 근거 — 원인이 구조적으로 규명됨
공용 계단 `strategy_common_hold_sell_v1.py:499-503`:
```
peak +1.0% 도달 → 고점대비 -1.0% 하락 시 매도
peak +3.0% 도달 → -1.5%
peak +6.0% 도달 → -2.0%
```
**첫 계단이 `발동 +1.0% / 되돌림 -1.0%` 다.** 고점 +1.0% 찍고 -1.0% 되돌리면
진입가 대비 **≈ 0%** 에서 매도된다. 수수료 0.2% 를 빼면 마이너스다.
실측 9건 평균 **+0.22%** 는 이 계단의 수학적 귀결이지 버그가 아니다.
(비교: `COMMON_PEAK_FLOW_EXIT` 7건은 평균 +1.70%)
