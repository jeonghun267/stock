# 지시서 — 종가매수 통합 수리 (게이트 완화 + 점수 공통모듈 + TOP200 관찰판)

**이 지시서는 지시서_종가매수_재생게이트완화_20260828.md 와 지시서_종가매수_TOP200선별판_20260828.md 를 대체한다.**

## 0. 왜 묶는가

실행기는 고칠 때마다 재생 자물쇠가 하루씩 리셋된다(엔진 해시 검사).
따로 고치면 이틀을 잃고, 한 번에 고치면 리셋 1회로 끝난다:
**주말~월 08:00 사이 일괄 수정 → 월 15:17 마지막 재기준 → 화 15:17 LIVE 후보.**

## 1. 집행 시점

주말 또는 월요일 08:00 이전. 장중(08:40~15:30) 편집 금지.
집행 후 월요일 15:17 전까지 이 파일을 아무도 다시 만지지 않는다(해시 동결).

## 2. 작업 A — 재생 게이트 완화 (`_replay_entry_audit`, 1096행~)

1. `if eligible < 1: raise` 제거 → 리포트에 `"eligible_candidates": <수>` 기록
   (0이면 0으로 정직하게). 판정 재현 전건 일치가 유일한 PASS 기준.
2. 해시/설정 불일치 raise는 유지하되 메시지 구분:
   `ENGINE_CHANGED_REBASELINE: ...` / `CONFIG_CHANGED_REBASELINE: <키>`.
   동작(당일 LIVE 불가)은 불변 — 바뀐 코드로 옛 감사 통과는 금지.

## 3. 작업 B — 원점수 공통모듈 분리

1. 신규 `RUN\eod_gap_score_common_v1.py`: mode_pick 내부의 원점수 계산
   (거래대금+종가+폭발 및 부속 계산)을 **순수 함수로 이동**. 입력=시세·거래대금
   등 값, 출력=점수·성분. **브로커·주문·TR·env 부작용 임포트 금지.**
2. 실행기 mode_pick은 이 함수를 호출(계산 의미 1도 변경 금지 — 순수 이동).
3. **점수 동일성 회귀 필수**: 오늘(8/28) 감사에 기록된 후보 40개의 점수를
   새 모듈로 재계산 → 전건 일치(예: 041190=69.1) 증명. 하나라도 다르면 중단·보고.

## 4. 작업 C — TOP200 주문 0 관찰판

1. 신규 `RUN\eod_gap_top200_shadow_v1.py`: 공통모듈 호출.
   가격(1만원 이하)·시총(SAFEPLUS_MIN_MARKETCAP) 선제외 → 거래대금 상위 200 →
   원점수·통일점수 분리 기록 → 원점수 60~70 후보 산출.
2. 산출물: `data\eod_gap_top200_shadow_YYYYMMDD.json`(후보·점수·제외사유·요약) +
   `data\LOG\eod_gap_top200_shadow.log`.
3. ⛔ TR 설계 — 둘 중 택1, 보고에 명시 (8/13 BATCH_TR 실사고 규칙):
   (a) 15:05~15:12 프리페치 후 15:18 판정은 캐시만 / (b) TR 0 + 커버리지 정직 기록.
   **15:15~15:26 창 신규 TR 0을 증명할 것.**
4. 주문 API 임포트 자체 금지. 태스크 등록은 명령어만 보고(친구님 실행).

## 5. 공통 제약

- 수정 파일: 실행기 1개 + 신규 2개 + 테스트 파일. 그 외 무접촉.
- 백업: `RUN\backup\eod_gap_live_executor_v1_20260828_before_unified_repair.py`
- 명부/기준표 커버 밖 재확인 출력 첨부 (8/28 실측: 등록 없음).
- 실행 프로세스 재시작 금지. 전체 [UNVERIFIED] — 화요일 15:17 재생이 첫 검증.

## 6. 완료 증거

1. diff 요약(실행기 변경 줄 범위 — 게이트 함수 + 점수 이동 호출부만인지)
2. py_compile 3파일 + 테스트: 기존 15 + 게이트 eligible=0 PASS 1 + 점수 동일성 1
3. 점수 동일성 회귀 결과(40건 전건 일치 표)
4. TOP200 드라이런 1회(오늘 자료로 가능한 범위 + 커버리지)
5. TR 창 회피 증명 + 태스크 등록 명령어

## 7. 시간표 (예상)

- 주말: 집행 + 클로드 검증
- 월 15:17: `ENGINE_CHANGED_REBASELINE` 마지막 1회 → 새 기준 캡처
- 화 15:17: 재생 PASS(후보 0이어도) → LIVE → 후보 있으면 **사상 첫 종가매수**
- TOP200판은 월요일부터 후보 수를 병행 기록 → 실전 풀 확대 여부의 판단 재료
