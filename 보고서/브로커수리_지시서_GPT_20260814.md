## 3. 시켜야 할 것 — 우선순위

### 🔴 1순위: TR 대기 루프를 요청별로 분리 (근본 수리)

현재: 모든 TR 이 `tr_loop` 하나를 공유 → 남의 응답이 내 대기를 깨움 → 가짜 TIMEOUT.
요구: 요청(rqname)별로 대기/완료 신호를 분리해, 자기 응답에만 깨어나게 한다.

- 브로커 재시작이 필요하므로 **반드시 장 마감 후(15:30 이후)**.
- 회귀 검증: 재시작 후 ①1분봉 수집 사이클에서 timeout 0 근접 ②S02 잔고조회 성공
  ③일봉 `GetCodeListByMarket` 즉시 성공.

### 🟡 2순위: 좀비 감지 워치독 (8/13 승인분, 미착수)

**좀비 지문 = "응답 전부 TIMEOUT + OK 0건"** — heartbeat·PID·last_request_ts 는 전부 정상으로
보이므로 기존 워치독이 못 잡는다. 90초 창에서 전량 TIMEOUT 이면 브로커 강제종료·재기동.
검증은 8/13·8/14 로그 재생으로.

### 🟢 3순위 (참고): 지수 조회 인증차단 잔존

`TR authentication blocked: this request type does not use IPC authentication` 을 맞는다.
1분봉 본체(종목 조회)와는 무관하고 영향이 작다. 1·2순위 끝난 뒤에 봐도 된다.
