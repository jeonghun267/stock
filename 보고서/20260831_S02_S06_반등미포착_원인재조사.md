## 증거 B — 죽은 자리는 flow_flip

OBSERVE_WAIT 사유 분포(중복 포함): `NO_FLOW_FLIP` 101 / 102행.
`NO_VALID_PULLBACK` 51, `NO_SECOND_REBOUND` 44, `NO_FLOW_ACCEL(_DATA)` 60.

수급자료가 실린 80행 기준:
- `flow_flip == O` : **0건**
- 저점 前 매도우위(=flip 이 가능한 상태) : 39행뿐
- 저점 後 매수우위 : 41행

즉 **하루 종일 매수우위였던 종목은 "저점 전 매도우위"가 성립하지 않아 flip 이 구조적으로 불가능**하다.
예) 펩트론 10:55 → pre 매수/매도 = 1,419,420 / 1,088,119 (이미 매수우위) → flip 영구 X.
    저점 후엔 870,600 / 356,993 로 매수 2.4배인데도 진입 불가.
