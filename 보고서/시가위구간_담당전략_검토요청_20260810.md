## 0. 왜 이 문서가 생겼나

당신이 오늘 S01에 넣은 ②번 조건(`low >= opening` 이면 `PULLBACK_BELOW_OPEN_NOT_SEEN`)으로
**S01 은 "시가 아래로 눌린 종목"만 보게 확정됐다.**

그 결과 **"시가 위에서 계속 오르는 종목"을 아무 전략도 안 보는 구간**이 생겼다.
오늘 실측으로 그게 **65종목**이고, 그중 상당수가 크게 올랐다.

운용자 제안:
> **"베이스 5번을 아침 9시부터 시작해서 1번이 놓치는 것들을 잡을 방법이 있을까?"**

그런데 **당신이 이미 ③번으로 같은 자리를 보는 그림자를 넣었다**
(`ABOVE_OPEN_REBREAK_SHADOW`: 시가 위 +1% 상승 → 되밀림 → 수급 재가속 → 직전고점 2틱 재돌파).

**즉 같은 자리를 노리는 후보가 둘이다. 중복인지 보완인지 먼저 가려야 한다.**

## 2. 후보 둘의 성격 차이

| | S01 그림자 `ABOVE_OPEN_REBREAK` | S05 장중 베이스 돌파 |
|---|---|---|
| 무엇을 보나 | **당일** 시가 위 +1% → 되밀림 → 직전고점 재돌파 | **전일 분봉으로 만든 30분 베이스**를 돌파 |

| 기동 | S01 신호기(08:55:30)에 얹혀 있음 | **09:25** (회전엔진 + 자동승인 동시) |

| 확인 조건 | 5~10초 수급 재가속 + 2틱 연속 재돌파 | 거래량 3배(`S05_BASE_VOLX=3`) + 리더 편입 |

## 3. 점검 요청 5건

### ① 역할 중복 판정 ← 이게 먼저다
**위 65종목에 두 조건을 각각 적용해 교집합을 세어 달라.**
- 겹침이 크면 → 하나만 살린다(그림자 하나로 충분할 수 있다)
- 안 겹치면 → 둘 다 살릴 근거가 생긴다

### ② 09:00~09:20 구간에서 어느 쪽이 유효한가
S05 는 전일 베이스를 쓰므로 **당일 25분을 기다릴 이유가 원래 없다**(베이스가 이미 만들어져 있다).
그런데도 09:25 시작인 이유가 코드 주석·`DOCS\새전략_목록.md`·
`DOCS\strategy05_base_breakout_quant_research.md` 어디에도 적혀 있지 않다.
**개장 직후 25분의 변동성이 베이스 돌파 판정을 망가뜨리는 이유가 있는가?**
(있다면 앞당기면 안 되고, 없다면 이력적 잔재일 뿐이다.)

### ③ S05 를 09:00 으로 옮길 때의 기술적 조건
`SAFEPLUS_STRATEGY05_LIVE.cmd` 가 09:25 에 **두 가지를 같이** 한다:
```
strategy_05_preflight_v1.py --approve   (그날 승인 발급)
회전 엔진 기동
```
실측(8/10): preflight json 09:25:11 → rotation lock 09:25:12.
**회전엔진만 앞당기면 승인이 없어 실전이 안 켜진다.**
⚠️8/5 에 preflight 접두어 하나가 빠져 S01~S03 이 통째로 못 뜬 사고가 있는 자리다.
둘을 함께 옮기되 그 사고가 재발하지 않을 설계는?

### ④ 검증 자료는 이미 쌓이고 있다
```
SAFEPLUS_BASE_BREAKOUT_SHADOW   09:00 기동  ← 그림자
SAFEPLUS_STRATEGY05_LIVE        09:25 기동  ← 실전
```
**그림자가 정확히 09:00 에 돈다.** 장부 `data\base_breakout_shadow_ledger.json` 며칠치에서
**09:00~09:25 진입 건수와 성과**를 뽑으면 "앞당기면 얻는 것"이 그대로 나온다.
⚠️ 8/10 장부는 **40바이트(사실상 빈 상태)** — 그날 이 구간 진입은 0건일 가능성이 크다.
하루로 판단하지 말 것(7/31 에 하루치로 문턱 골랐다가 전부 나빠진 이력).

### ⑤ 슬롯 기회비용
S01·S02·S03·S05 는 **공용 6슬롯**을 나눠 쓴다(S06 만 독립).
S05 가 아침에 사면 S02 가 쓸 자리를 뺏을 수 있다.
채점은 **S05 단독 수익이 아니라 기회비용까지** 넣어야 한다.
(8/10 은 최대 2/6 만 찼으니 그날 기준으로는 여유가 있었다.)

## 4. 결정 구조 (제안)

```
①번 교집합 계산
   ├─ 겹침 크다  → S05 는 09:25 유지. S01 그림자만 며칠 쌓아 채점
   └─ 겹침 작다  → ④번 그림자 장부로 S05 09:00 이설의 실익 측정
                    → 실익 있으면 ③번 설계로 배선 (마감 후)
```

**어느 쪽이든 "며칠치 그림자 → 채점 → 배선" 순서를 건너뛰지 않는다.**

- 📌 최소 주가 1만원 관문이 전 전략에 걸려 있다(저가주는 애초에 제외됨)
