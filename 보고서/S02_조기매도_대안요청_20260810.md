## 2. 원인 — 꼭지에서 **1% 절대값** 되밀리면 판다

8건 전부 매도 사유가 `COMMON_PEAK_FLOW_EXIT` 이고 로그의 `drop` 값이 **0.82~1.14%** 다.
즉 **최고점 대비 약 1%p 되밀리는 순간 매도**한다.

### 🔑 절대값 고정의 부작용 — 작게 오른 종목일수록 더 심하게 잘린다

| 종목 | 최고점 mfe | 챙긴 gross | **최고점의 몇 %를 챙겼나** |
|---|---|---|---|
| 오이솔루션 | 2.068% | 0.940% | **45%** |
| RFHIC | 2.549% | 1.373% | 54% |
| 스피어 | 4.365% | 2.579% | 59% |
| 코오롱티슈진 | 3.264% | 1.989% | 61% |
| 에이치브이엠 | 3.030% | 1.961% | 65% |
| 씨이랩 | 3.293% | 2.219% | 67% |
| 엔켐 | 2.743% | 1.899% | 69% |

최고점 2%인 종목에서 1% 되밀림 = **절반 반납**.
최고점 4%인 종목에서 1% 되밀림 = 23% 반납.
**하필 덜 오른 놈을 더 가혹하게 자르는데, 그 오이솔루션이 판 뒤 +11.92% 로 갔다.**

## 3. 🚨 그러나 "끝까지 홀딩"이 답은 아니다 — 3승 3무 2패

```
더 갔다  : 오이솔루션 +11.92%(30분) · 엔켐 +7.66%(30분) · RFHIC +4.06%(60분)
비슷     : 씨이랩 · 지엔씨에너지 · 코오롱티슈진
팔길 잘함: 스피어 -3.10%(30분) · 에이치브이엠 -2.62%(60분)
```
홀딩으로 바꾸면 큰 걸 먹는 대신 이긴 걸 토해낸다. 한쪽으로 단정하면 안 된다.

### 약한 단서 (표본 부족 — 확정 아님)
```
score 3/4 (꼭지신호 강함) : 스피어 1건 → 팔길 잘함
score 2/4 (약함)         : 나머지 6건 → 엇갈림
```
3/4 가 **1건뿐**이라 하루로는 아무것도 못 정한다.

## 4. Claude 가 낸 대안 4개 (검토·개선 요청)

### ① drop 문턱을 최고점 **비례**로 (추천)
```
지금:  매도 = 최고점 - 1.0%p (절대값 고정)
대안:  매도 = 최고점 × (1 - k)   예: k=0.30 이면 최고점의 30% 되밀림까지 허용
```
최고점 2% → 0.6% 만 허용 / 4% → 1.2% 허용. **작은 놈을 덜 자른다.**

### ② drop 절대값 완화 (1% → 1.5~2%)
가장 단순하나 **큰 놈도 같이 늦춰져** 스피어(판 뒤 -3.10%) 같은 건이 손해로 바뀐다.

### ③ `score 2/4` 면 매도 보류, `3/4` 이상만 매도
표본이 1건뿐이라 근거가 약하다. 며칠치 필요.

### ④ 재진입 활용 — 이미 열려 있다
로그에 `cycle=1/2` 가 찍힌다 = **같은 종목 하루 2회까지 매수 가능**.
오이솔루션을 10:07 에 팔고 다시 샀다면 +11.92% 를 잡을 수 있었다.
**왜 재매수가 안 됐는지 아직 확인 못 했다**(조건 미충족인지, 슬롯 문제인지).

### ⛔ 분할 매도는 불가능
현재 **1종목 1주** 체제라 절반을 팔 수 없다. 수량을 늘리기 전엔 성립하지 않는다.

### ⛔ 트레일 매도는 금지
2026-08-04 에 운용자가 확정 금지한 항목이다. 트레일을 쓰는 제안은 받아들여지지 않는다.
